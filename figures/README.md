# Figures

This folder contains scripts for generating the main and supplementary figures used in the manuscript.

The scripts in this folder are used for visualization only. They do not train the proposed model, run benchmark models, or perform the main sensitivity analyses. Most figure scripts read processed CSV tables, prediction files, cached features, or summary results generated by other parts of the repository, and then export publication-style figure panels.

## Recommended workflow

Before running the figure scripts, make sure the required data and result tables have been generated.

A typical workflow is:

```text
1. Prepare the data under data/
2. Train or evaluate the proposed framework
3. Run post-training analysis scripts under analysis/
4. Run benchmark or measurement-sensitivity scripts if needed
5. Run the plotting scripts under figures/
6. Export figure panels under results/figures/
```

Run figure scripts from the repository root, for example:

```bash
python figures/plot_fig3a_prediction_scatter.py
```

Running from the repository root is recommended because the scripts use relative paths to read input files and save output figures.

## Output location

Most figure scripts save generated images under:

```text
results/figures/
```

with subfolders for main or supplementary figures, for example:

```text
results/figures/main/
results/figures/supp/
```

The exact output path may differ by script. Please check the `SAVE_DIR` or output-path configuration inside each script if needed.

## Input dependencies

Different figure scripts require different input files. Depending on the figure, the required inputs may include:

* raw Excel data under `data/`;
* trained-model prediction tables generated by `analysis/`;
* benchmark result tables generated by `benchmark/`;
* measurement-sensitivity summaries generated by `measurement_sensitivity/`;
* manually prepared summary CSV files for selected comparison plots.

If a figure script fails because an input file is missing, first check whether the corresponding analysis, benchmark, or sensitivity script has been run.

## Notes

* This folder should contain plotting scripts, not large generated image files.
* Generated figures should be saved under `results/figures/`.
* Run scripts from the repository root to avoid path errors.
* Some scripts may contain figure-specific settings such as selected SOC level, pulse-width subset, color palette, output DPI, or file names. Check the configuration section at the top of each script before running.
* Python cache folders such as `__pycache__/` should not be committed to the repository.
